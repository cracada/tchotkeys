# TCHotkeys


- 在tc中绑定快捷键呼出，也可独立运行
- 自动读取wincmd.ini获取自定义快捷键
- 方向键、Home\PGDN等特殊按键，需要加按Ctrl来进行匹配
- 蓝色文字表示是新增或覆盖了默认的快捷键

- --exec 列表内的条目可双击击或按Enter执行，否则仅复制
- --export 导出mnu格式的快捷键汇总菜单
- --export-txt 导出txt格式的快捷键汇总文件
- --patch 校验同目录下input.mnu文件并输出修正后的菜单，仅测试！
- --path=d:\totalcmd,用来强行指定tcmd的路径

- tc_hotkeys.txt为默认快捷键，tc_zdykeys.txt为外部自定义的快捷键如ahk等
